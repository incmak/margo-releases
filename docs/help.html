Install Margo, manage the whole Library, and keep five notes at the edge.

Install and start

  1. Download the current ZIP and compare its published SHA-256 checksum.
  2. Open the ZIP and move Margo.app to Applications.
  3. Try to open Margo once, then dismiss the unsigned-app warning.
  4. Open System Settings, choose Privacy & Security, select Open Anyway, and confirm.

Apple has not checked or notarized this free build. Continue only if you trust the file and understand the override.

Read Apple’s security guidance Download the 0.2.1 checksum

Reopen Margo

Open Margo from Applications, select Open Margo from its menu bar icon, or click its Dock icon. Closing the Library window does not quit the app.

Library and search

Margo opens as a normal resizable Mac app. Choose New Note or press ⌥⌘N, then type. Margo saves plain text automatically.

The sidebar has three non-overlapping sections:

At the Edge
Up to five active notes shown from the right edge of each display.
Library
Every other active note. The Library has no five-note limit.
Archive
Notes set aside without deleting their text.

Use the sidebar search field to filter all three sections. Search checks the complete note text, not only the first-line label.

The five edge slots

Move the pointer to the right edge of a display to fan the notes open. Select a paper tab to edit its sticky. Press Esc to close the expanded deck.

When fewer than five edge slots are used, a new note enters the edge. When all five are used, Margo names the oldest unpinned edge note and offers three choices:

Move and Create
Keep the named note in the Library and open the new note at the edge.
Create in Library
Leave all five edge notes where they are and open the new note in the full window.
Cancel
Make no placement or note change.

Pin keeps an edge sticky open when Margo loses focus and protects that note from automatic replacement. If all five edge notes are pinned, new notes open in the Library.

Choose Open in Margo on a sticky to close the small editor and open the full Library with the same note selected.

Move, archive, and delete

Select an active note in the Library and use its toolbar:

Put at Edge
Move a Library note into a free edge slot. If the edge is full, Margo asks before replacing the oldest unpinned note.
Remove from Edge
Keep the note active in the Library and clear its pin.
Archive
Remove the note from the active Library and edge without deleting its text.
Restore to Library
Return an archived note to the Library without displacing an edge note.

Delete removes the selected note. Choose Undo Delete from the menu bar or press ⌘Z to recover the latest deletion. Press ⌘⌫ to delete from the full Library editor.

Import, export, and backup

Open Library Tools from the toolbar for complete file controls.

Import Text Files
Choose one or more UTF-8 plain-text files. Available edge slots fill first and every remaining import stays in the Library.
Export
Save the selected note as a plain-text file with a safe filename based on its first line.
Back Up Library
Create one .margo file containing every note, color, date, edge placement, archive state, and pin state.
Restore Backup
Validate a .margo file, preserve a recovery copy of the current Library, then replace it.

Displays and shortcuts

Margo creates one edge deck for every connected display. Global actions target the display under the pointer, then fall back to the primary display.

⌥⌘N
Create a note.
⌥⌘M
Show or hide edge notes.
⌘Z
Undo the latest deletion.
⌘⌫
Delete the selected Library note.
Esc
Close an expanded edge deck or sticky.

Normal desktop Spaces are supported. Full-screen app Spaces are not supported in the current beta.

Launch at Login is available from the Margo menu bar and remains off until you enable it.

Data and privacy

Margo stores its version 3 Library at ~/Library/Application Support/Margo/notes.json. The file contains note text, marker colors, note order, timestamps, edge placement, archive state, and pin state.

Margo has no account, server, analytics, ads, AI, sync, crash SDK, or content upload. Opening Help, a release, Apple guidance, or the feedback link hands that explicit action to your browser.

Deleting Margo.app does not delete the Library. Back it up first, then remove the Margo folder from Application Support if you want to erase the local data.

Troubleshooting

macOS will not open Margo

Confirm that Margo is in Applications. Try to open it once, then use Privacy & Security to choose Open Anyway. Review the checksum and Apple guidance before overriding the warning.

The edge notes are missing

Press ⌥⌘M or choose Show Edge Notes from the menu bar. Move the pointer to the right edge of the display you want. Leave a full-screen app Space if one is active.

A note will not move to the edge

Five pinned notes occupy all five slots. Unpin or remove one edge note, then use Put at Edge again.

Margo reports a save problem

Margo keeps the current text in memory and shows the storage error. Resolve the reported permission or disk problem before quitting. If the Library file is damaged at launch, Margo moves it to a timestamped recovery file instead of overwriting it.
