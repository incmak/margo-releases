Install it with eyes open.

Apple has not checked this free build. Review the release and checksum first. Continue only if you trust the download.

  1. 1

    Move it. Download the ZIP, open it, and move Margo.app to Applications.

  2. 2

    Let macOS block it once. Try to open Margo, then dismiss the unsigned-app warning.

  3. 3

    Open it deliberately. In Privacy & Security, choose Open Anyway and confirm.

Read Apple’s security guidance Download the 0.1.0 SHA-256 checksum
Why is this unsigned?

Margo is a free beta and is not notarized yet. macOS may quarantine unsigned downloads, so use Open Anyway after checking the checksum.

Stored here. Sent nowhere.

Your notes and their Library state stay in one JSON file on your Mac. Margo has no account, server, analytics, ads, AI, sync, crash SDK, or content upload.

Read the privacy note

Made for the Mac you use.

Margo supports Apple-silicon Macs on macOS 15 or later, every connected display, and normal desktop Spaces. Full-screen app Spaces are not supported in the current beta.
